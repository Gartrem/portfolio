# Тестовое задание — интернет-магазин «Петрушка Зеленая»

В репозитории оформлено решение трех заданий:

1. Анализ требований к функционалу корзины.
2. Проектирование REST API для экрана выбора магазина партнеров.
3. Верхнеуровневая архитектура PUSH-уведомлений для мобильного приложения.

## Структура

- [`task-1-requirements-analysis.md`](./task-1-requirements-analysis.md) — анализ противоречий, исправленная версия требований и вопросы бизнес-заказчику.
- [`task-2-rest-api.md`](./task-2-rest-api.md) — пример REST API запроса и JSON-ответа для экрана выбора магазина.
- [`task-3-push-architecture.md`](./task-3-push-architecture.md) — описание архитектуры PUSH-уведомлений.
- [`diagrams/push-architecture.md`](./diagrams/push-architecture.md) — верхнеуровневая схема архитектуры в формате Mermaid.

## Кратко по решению

В первом задании выявлены логические противоречия в требованиях к корзине: лимиты, удаление товара, фиксация и обновление цены, реклама и неполные сценарии.

Во втором задании предложен REST API для получения списка магазинов партнеров с логотипами, временем доставки и ссылкой на внешний ресурс.

В третьем задании предложена событийная архитектура PUSH-уведомлений: бизнес-сервисы публикуют события в брокер сообщений, а отдельный Notification Service отвечает за шаблоны, настройки пользователя, очередь отправки, отправку через FCM/APNs и логирование результата.

## Основная идея архитектуры PUSH

Бизнес-сервисы не должны напрямую отправлять PUSH-уведомления. Они только создают события, например `ORDER_CANCELLED`, `CART_ABANDONED` или `MARKETING_CAMPAIGN_STARTED`. Далее Notification Service централизованно обрабатывает эти события и отправляет уведомления пользователям.

Такой подход позволяет:

- добавлять новые типы уведомлений без доработки всех бизнес-сервисов;
- централизованно управлять шаблонами и настройками пользователя;
- контролировать лимиты рекламных рассылок;
- логировать статусы отправки;
- повторять отправку при временных ошибках;
- масштабировать отправку PUSH независимо от остальных сервисов.
